개인정보 및 데이터 이용 안내

이 안내는 쭝터기 홈페이지의 초기 제공 기능을 설명합니다. 프로그램 EXE 자체의 통계 수집·동의 설정과는 구별됩니다. 최종 수정: 2026년 11월 12일.

1. 홈페이지의 데이터 저장

어비스 일정에서 선택한 서버와 수동 PvP 기록장은 이용 중인 브라우저의 저장 공간(localStorage)에 보관됩니다. 현재 허브 기능은 보완을 위해 중지됐으며, 이전 허브 설정이 브라우저에 남아 있을 수 있습니다. 현재 홈페이지는 수동 PvP 기록장에 입력한 캐릭터 이름과 RP 값을 Supabase 또는 별도 쭝터기 서버에 업로드하지 않습니다. 최신 업데이트 내역 조회에 GitHub 공개 API를 이용하며, 해당 요청은 GitHub 서비스에 전달됩니다. 브라우저 데이터 삭제나 다른 기기로 이동하면 해당 기록이 사라질 수 있으므로 JSON 백업 기능을 제공하고 있습니다.

2. 외부 서비스 이용

  • GitHub Pages로 홈페이지를 게시할 수 있으며, GitHub Releases API에서 공개된 프로그램 버전 정보를 조회합니다.
  • 문의·건의사항 폼은 Supabase Edge Function으로 직접 전송됩니다. GitHub 로그인은 필요 없으며 접수된 내용은 공개 이슈로 게시되지 않습니다. 운영자 인증을 통과한 사용자만 문의 내용을 조회할 수 있습니다.
  • 웹 서비스 제공업체가 통상적인 접속·보안 로그를 처리할 수 있습니다. 이 홈페이지가 모든 네트워크 기록을 통제하거나 저장하지 않는다고 보장하지는 않습니다.

3. 익명 문의 수집·처리

문의 유형, 제목, 내용, 선택 입력한 닉네임, 접수 시각, 처리 상태 및 접수번호를 보관합니다. 악용 방지 목적으로 요청 IP를 일별로 해시 처리한 값을 저장하며, 문의 데이터 테이블에는 IP 원문을 저장하지 않습니다. 호스팅 및 보안 서비스의 일반적인 접속 로그는 별도로 처리될 수 있습니다. 관리자 문의함에서 처리 및 삭제할 때까지 보관될 수 있으며, 로그인·이메일 주소 없이 제출하므로 개별 답장은 제공하지 않습니다.

문의 취소·삭제가 필요하다면 접수번호를 기재해 다시 요청해 주세요. 문의 내용에 계정 비밀번호·인증번호 또는 타인의 개인정보를 입력하지 마세요.

4. 프로그램과의 관계

배포 중인 쭝터기 EXE는 별도 기능으로 동의 기반 익명 설치·사용 통계를 처리할 수 있습니다. 홈페이지의 수동 PvP 기록장은 이 시스템과 연결되어 있지 않습니다. 추후 로그인·동기화·공유 기능을 추가하려면 공개 범위, 보관 기간 및 삭제 정책을 검토하고 안내를 갱신합니다.

5. 사용자가 할 수 있는 일

웹 기록장의 각 기록을 삭제하거나 전체 삭제할 수 있습니다. JSON 파일로 기록을 내보내거나 복원할 수 있습니다. 저장 정보는 브라우저별로 관리되며 이 홈페이지에서 다른 기기의 브라우저 기록에 접근하지 않습니다.

개선 제안 또는 안내 수정 요청은 오류·문의 페이지에서 진행할 수 있습니다. 제보에는 계정 비밀번호나 개인 정보를 입력하지 마세요.
